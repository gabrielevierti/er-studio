## Simulator

The mirror is the real 576×288 mono-green display, updated live. Not an emulation — the pixels come from the simulator's own framebuffer.

| | |
| --- | --- |
| Run | `Cmd+Alt+R` |
| Stop | `Cmd+Alt+S` |
| Up / Down | `Cmd+Alt+↑` / `Cmd+Alt+↓` |
| Click | `Cmd+Alt+Enter` |

The input pad under the mirror does the same. `ER Studio: Capture Simulator Screenshot` writes a PNG into your workspace.
